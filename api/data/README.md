# Utah places

`utah-places.json` is a short list of Utah towns and ZIP Code Tabulation Areas.

Source: U.S. Census Bureau, 2023 Census Gazetteer Files for places and ZIP Code Tabulation Areas. A U.S. government work is public domain.

Town names drop the Census label (city, town, CDP, and so on). If two places share a name, the one with more land area is kept. ZIP rows whose centroid falls outside Utah are left out. A ZIP is labeled with the nearest town in this file.
